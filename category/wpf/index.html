    C# 的資料繫結

    什麼是資料繫結?

    資料繫結(Data Binding)是一種讓資料跟頁面連結再一起的方式，當參數變動的時候，會利用通知來通知頁面做變化，這部分在很多的前端或Native原生介面常常會出現這種東西，不過大多數都只會記得這種設計架構，他其實就是MVVM

    MVVM

    MVVM 是一種設計模式，可以類比於之前網路的MVC設計模式，而MVVM的模型主要以這三個為主：

    • Model：資料格式與資料處理層，往往跟後端與底層有著強連結，也是制定資料格式的地方，不需要處理任何界面問題。
    • View：也就是頁面。
    • View-Model：介於View與Model之間的橋樑，主要負責介面的互動根與Model資料索取的相關函式都算是，這個模組主要就是要解耦介面與資料，以方便做單元測試

    WPF的Converter

    什麼是轉換器(Converter)?

    轉換器(Converter)是WPF在xaml的一種工具之一，他主要是將原本不符合放在這個控制項上的參數轉換成控制項可以接手的參數，說直白就是在做一種資料轉換跟清洗的觀念，其實在資料繫結或是東西出來後你要轉換也是能達到相同的效果，那這樣為什麼要去使用它呢?

    資料邏輯與業務邏輯

    一般來說，一個頁面的會呈現的資料有很多種，我們可以把它分成兩大類，分別是跟：

    • 資料邏輯：也就是資料上的單純相互轉換，例如當我的亮度(整數)大於或小於多少的時候，我必須在我的介面上顯示亮度為高，我就必須將亮度(整數)轉成字串「高」，這樣才可以，這就是一般的資料轉換。
    • 業務邏輯：也就是資料與介面互動屬性的互相轉換，例如當我的亮度(整數)大於或小於多少的時候，我必須在我的介面上顯示一個紅色的驚嘆號來明顯表示，這時候我就必須讓Icon的Visibility(可視)顯示為True來顯示，這個就跟資料的顯示不同，他是根據資料改變其互動屬性，那就不是單純的資料轉換而已。

    Xaml的各種Resource

    Xaml的Resource區塊

    什麼是Resource?

    無論是WPF或是Windows Form，都會有所謂的「資源」需要去載入，例如應用程式的圖示、裡面的圖案、圖片，甚至到裡面的字串或整數、檔案，這些外來的，偏向靜態或是固定要用的東西都會去放在資源裡面，而不同的程式，儲放資源的方式也不同。例如Winform因為沒有放資源的程式碼與區域，所以都會使用Visual Studio 的資源管理器來去做處理，而WPF有Xaml的資源管理區域做資源的載入跟管理，所以絕大多數不需要管理，而衍生出來的，就是Xaml的Resource的區塊。

    WinForm/WPF 自動調整DPI

    無論是WinForm、WPF，只要你是傳統Desktop的程式，就一定會遇到高DPI的程式自動調整，當然也可以不用到這麼麻煩，使用前進執行檔內容修改這兩個東西就可以：

    但要知道這樣的方式有時候是不太好的，因為程式大多都是設計在縮放大小為100%的狀況下，一打開就模糊難免造成使用者的不舒服，所以我們要在程式碼增加以下部分，讓程式打開時就順應當下主螢幕的縮放大小去做調整，這樣每次打開就都會是清晰正常的視窗了。

    以下是WinForm當中主要開啟程式的 Program.cs：

    using System;
using System.Collections.Generic;
using System.Linq;
using System.Threading.Tasks;
using System.Windows.Forms;
using System.Runtime.InteropServices;

namespace WebICTest
{
    static class Program
    {
        /// <summary>
        /// 應用程式的主要進入點。
        /// </summary>
        [STAThread]
        static void Main()
        {
            //自動修改DPI
            if (Environment.OSVersion.Version.Major >= 6)
            {
                SetProcessDPIAware();
            }
            Application.EnableVisualStyles();
            Application.SetCompatibleTextRenderingDefault(false);
            Application.Run(new Form1());
        }

        //高DPI自動設置(可以不用管)
        [DllImport("user32.dll")]
        public static extern bool SetProcessDPIAware();
    }
}
